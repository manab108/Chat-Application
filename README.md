# Full Stack Chat Application

A real-time chat application built with React and Firebase, allowing users to sign up, create profiles, and chat with others. The app features a responsive UI, real-time messaging, and user presence indicators.
<br/>
Check out the live app on Vercel: [Chat App](https://chat-application-v1-five.vercel.app/)

# Features
* User Authentication: Sign up, log in, and log out using Firebase Authentication.
* Profile Management: Set a username, name, and bio.
* Real-Time Messaging: Send and receive text messages instantly using Firebase Firestore.
* User Search: Find and start chats with other users by searching their usernames.
* Responsive Design: Mobile-friendly interface with toggleable chat and sidebar views.
* Notifications: Error and success messages displayed via react-toastify.
* Online Status: Green dot indicates if a user was recently active.

# Tech Stack

* Frontend: React, React Router, React Toastify
* Backend: Firebase (Authentication, Firestore)
* Styling: Custom CSS
* Environment: Node.js, Create React App

# Usage

* Sign Up: Create an account with a username, email, and password.
* Set Profile: Enter your name and bio.
* Search Users: Use the search bar to find other users by username.
* Chat: Select a user to start a chat and send text messages.
* Logout: Click the menu and select "Logout".
